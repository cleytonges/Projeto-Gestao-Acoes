# Projeto de BI - Gestão de Ações | 2025

Este projeto simula um relatório de acompanhamento de ações utilizando **Power BI**. O objetivo é demonstrar habilidades em visualização de dados, organização de indicadores e estruturação de dashboards para tomada de decisão.

---

## 📊 Ferramentas Utilizadas
- Power BI Desktop
- Microsoft Excel (dados fictícios)

## 🔍 Principais Insights
- Total de ações: 247

- Atrasadas: 33
- Distribuição por responsável e origem da ação

## 🚀 Como Abrir o Relatório
1. Baixe o arquivo `GestaoAcoes.pbix` na pasta `Relatorio`.
2. Abra com o **Power BI Desktop**.
3. Explore os gráficos e tabelas interativas.
